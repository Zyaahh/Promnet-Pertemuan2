# Personal Website with HTML

## 📌 Deskripsi

Project ini merupakan hasil pembelajaran dalam membuat **personal website sederhana menggunakan HTML (HyperText Markup Language)**. Website dibuat sebagai media untuk memperkenalkan diri, menampilkan informasi pribadi, serta menampilkan beberapa project atau hasil kegiatan yang pernah dilakukan.

Dalam proses pembuatannya, saya mempelajari dasar-dasar HTML mulai dari struktur dokumen HTML, penggunaan heading, paragraf, gambar, tabel, hyperlink, hingga pembuatan navigasi antarhalaman.

## 🎯 Tujuan Pembelajaran

Tujuan dari project ini adalah:

- Memahami struktur dasar dokumen HTML.
- Mempelajari penggunaan berbagai elemen dan tag HTML.
- Membuat halaman website sederhana.
- Membuat navigasi antarhalaman menggunakan hyperlink.
- Menampilkan informasi pribadi dalam sebuah website.
- Mengatur struktur dan susunan konten pada halaman web.
- Mengenal proses penggunaan Git dan GitHub untuk menyimpan serta mempublikasikan project website.

## 🛠️ Teknologi yang Digunakan

- **HTML5** – digunakan untuk membuat struktur dan konten website.
- **Visual Studio Code** – digunakan sebagai text editor untuk menulis kode HTML.
- **Git** – digunakan untuk mengelola perubahan pada project.
- **GitHub** – digunakan untuk menyimpan repository dan mempublikasikan website menggunakan GitHub Pages.
